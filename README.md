# Entrance 3D viewer

ブラウザでエントランスを歩き、現状・折り上げ天井・パネル・木ルーバーを比較する公開プレビューです。

- 天井比較 Q3：折り上げの段差約380mm。木ルーバー上部は黒色スケルトンの想定設備。
- 色温度・明るさの調整、入口・EVホール・裏口への復帰。
- PCではドラッグで見回し、WASD/矢印キーで移動。
- 配信は可逆圧縮で約28MB（展開後約41MB）。寸法・設備・照明は検討用の仮定で、施工図や照度計算ではありません。

天井切り替え時の照明スロット数を固定し、通常描画・EV反射用シェーダーを初期準備します。内蔵GPUなどで操作が重い場合は右下の描画「操作を軽く」、またはURL末尾に `?render=responsive` を指定してください。移動・見回し中だけ画面と反射を軽くし、停止約180ms後に元の高精細へ戻ります。「自動」は実測したフレーム間隔に応じて調整し、「画質優先」は常に元の解像度を使います。設定はそのブラウザに保存します。影は元の解像度を維持し、3つの影の一時深度メモリを共有します。

静止中は描画とEV反射を再計算せず、移動・視点・照明・天井の変更で更新します。形状、テクスチャ、照明値、静止時と画質優先での描画・影・反射の解像度は維持しています。

GitHub Pagesの公開元はmainブランチのルートです。ビルドは不要です。設計方針は `design.html`。

外部CDNやChatGPTへのログインに依存せず、表示に必要なファイルを同梱しています。元図面・作業記録・認証情報は含めていません。3Dデータも公開ファイルです。
