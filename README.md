# Entrance 3D viewer

ブラウザでエントランスを歩き、現状・折り上げ天井・パネル・木ルーバーを比較する公開プレビューです。

- 天井比較 Q3：折り上げの段差約380mm。木ルーバー上部は黒色スケルトンの想定設備。
- 色温度・明るさの調整、入口・EVホール・裏口への復帰。
- PCではドラッグで見回し、WASD/矢印キーで移動。
- モデル約41MB。寸法・設備・照明は検討用の仮定で、施工図や照度計算ではありません。

GitHub Pagesの公開元はmainブランチのルートです。ビルドは不要です。設計方針は `design.html`。

外部CDNやChatGPTへのログインに依存せず、表示に必要なファイルを同梱しています。元図面・作業記録・認証情報は含めていません。3Dデータも公開ファイルです。
